# Supporting contracts

These documents define isolated or supporting capabilities. `AGENTS.md` at the
workspace root remains the controlling authority when documents differ.

- [`THREADS_LINKEDIN_ENGAGE.md`](THREADS_LINKEDIN_ENGAGE.md) defines Threads-first
  official-API collection, built-in AI stages and human-approved replies, plus
  separate LinkedIn organization ENGAGE.

- [`ENGAGE_CREATOR_MENTIONS.md`](ENGAGE_CREATOR_MENTIONS.md) defines optional
  evidence-grounded creator connections within one ENGAGE topic run, with up to
  two reviewed native mentions in positive-support comments.
- [`ENGAGE_GOOGLE_PUBLISHING.md`](ENGAGE_GOOGLE_PUBLISHING.md) gives Google the
  native-label preparation, exact approval, handoff and single-comment commands,
  for any TikTok ENGAGE topic.
- [`ENGAGE_PUBLICATION_RECOVERY.md`](ENGAGE_PUBLICATION_RECOVERY.md) defines
  manual CAPTCHA completion, bounded worker supervision, offline interrupted
  attempt recovery and history-preserving same-text supersession.

- [`MUSICBRAINZ_RETIREMENT.md`](MUSICBRAINZ_RETIREMENT.md) defines the retired
  provider's no-request behavior, empty new-run defaults, and preservation of
  existing evidence and frozen run settings.
- [`MULTI_TOPIC_MUSIC_AUDIT.md`](MULTI_TOPIC_MUSIC_AUDIT.md) defines explicit
  TOTAL/EACH/CUSTOM quota planning and sequential exact-topic guarded MUSIC
  AUDIT children without quota redistribution, AI, or outbound action.
- [`POSTS_DISCOVERY.md`](POSTS_DISCOVERY.md) defines recency-first TikTok topic
  collection with an explicit publication window, post count, and isolated
  parent output linked to guarded evidence collection.
- [`MUSIC_DISCOVERY.md`](MUSIC_DISCOVERY.md) preserves the legacy artist-research
  contract for explicit continuation of existing runs and dossiers; new
  default discovery requests use POSTS DISCOVERY.
- [`AUDIO_ARCHIVE.md`](AUDIO_ARCHIVE.md) defines the isolated matched-M4A-and-
  MP3 retention workflow for evidence-ready rows in any compatible local
  project, including selected- and all-project batch execution.
- [`CROSS_PLATFORM_MUSIC_AUDIT.md`](CROSS_PLATFORM_MUSIC_AUDIT.md) defines the
  platform-neutral metadata importer.
- [`LINKEDIN_WORKFLOW.md`](LINKEDIN_WORKFLOW.md) defines isolated official-API
  LinkedIn Page collection.
- [`TIKTOK_ONE_TOP_CONTENT.md`](TIKTOK_ONE_TOP_CONTENT.md) defines read-only
  TikTok One link discovery and its LISTEN bridge.
- [`SOURCE_SCOPE.md`](SOURCE_SCOPE.md) records source, runtime-data, and backup
  boundaries.

- [`REGISTRY_REPAIR.md`](REGISTRY_REPAIR.md) defines offline source-identity
  repair, preserved immutable records, moved-file aliases, and encrypted backups.
